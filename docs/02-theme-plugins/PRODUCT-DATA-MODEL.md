# Product Data Model

## Goal
Define the initial WooCommerce product structure for Crystal Soul.

## Launch Scope
Initial launch products are bracelets.

## Product Model Strategy
Because the first launch is small, the product model should stay simple while remaining expandable.

## Initial Product Categories
Recommended launch category structure:
- Bracelets

Future categories may include:
- Necklaces
- Rings
- Raw Stones
- Tumbles
- Gift Sets
- Accessories

## Product Type Policy
Initial recommendation:
- use Simple Products unless a real variation need exists
- use Variable Products only for true size/material variations

## Global Attributes
Recommended initial attributes:
- Stone Type
- Bead Size
- Wrist Size
- Color
- Material
- Charm / Accessory
- Intention
- Zodiac
- Birth Month

## Attribute Usage Rules
- Use global attributes only if filtering, consistency, or future scalability requires them
- Do not create near-duplicate attributes
- Keep naming standardized
- Avoid mixing category concepts with attribute concepts

## Tags Policy
Use tags sparingly for soft discovery terms, not for structural classification.

## SKU Policy
Recommended SKU format example:
```text
CS-BR-ROSE-001
CS-BR-AMETHYST-002
