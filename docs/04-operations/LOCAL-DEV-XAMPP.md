# Local Development with XAMPP

## Goal
Define a simple, repeatable, low-risk local development setup for the Crystal Soul project using XAMPP.

## Local Environment Policy
- Local environment is used for testing, learning, and safe implementation before staging/production.
- No production credentials should ever be stored in local documentation or committed to Git.
- Local setup should stay simple and reproducible.
